Everything a stolen-token defense needs

One library that signs, binds, verifies and revokes — with batteries included.

Proof-of-possession tokens

Every request carries a fresh DPoP proof JWT signed by the device's private key. No key, no access.

Anti-replay protection

JTI tracking guarantees each proof is used exactly once — a captured request can never be replayed.

Device binding

Access tokens are cryptographically tied to device keys and fingerprints. Stolen tokens simply fail.

Token revocation

Built-in revocation stores let you kill compromised tokens instantly, before they expire.

Express middleware

Drop-in route protection. Wrap a route, read req.thumbprint, done.

Pluggable stores

Memory and Redis stores for replay and revocation state — swap implementations without touching your routes.

How it works

Three moving parts, one guarantee: the caller is the device the token was issued to.

01

Keys live on the device

The client generates an ECDSA P-256 key pair and registers the public JWK at login. The private key never leaves the device.

02

Every request is signed

Each API call carries a short-lived proof in the DPoP header — signed with the private key, unique per request, bound to the method and URI.

03

Server verifies everything

Middleware verifies the signature, rejects replays, and checks the token's key thumbprint against the proof. Mismatch means theft — rejected.

Quick start

Protecting your first route takes about two minutes.

Terminal 
// install
npm install dpop-auth
server.ts 
import express from 'express';
import { dpopAuth, createDPoPAuth } from 'dpop-auth';

const app = express();
app.use(express.json());

const auth = createDPoPAuth(SECRET_KEY, {
  algorithm: 'ES256',
  expiresIn: 300, // 5 minutes
  enableFingerprinting: true,
});

// protect your API routes
app.use('/api/protected', dpopAuth({
  secret: SECRET_KEY,
  enableFingerprinting: true,
}));

// protected endpoint
app.get('/api/protected/data', (req, res) => {
  res.json({
    message: 'Protected from scraping and token theft!',
    user: req.token.sub,
    device: req.thumbprint,
  });
});

app.listen(3000);
