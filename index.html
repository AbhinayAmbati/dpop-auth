A stolen token should be worthless

Bearer JWTs are passwords that never expire. dpop-auth binds every access token to the device key that earned it — proof on every request, replay protection, instant revocation.

Not a bearer token

A bearer token is a password that never expires — anyone holding it becomes the user. dpop-auth never trusts possession alone: the token is only half of the credential.

Proof on every request

Each API call carries a fresh ECDSA signature bound to the method, URI, and a one-time nonce. JTI tracking kills replays; revocation stores kill stolen tokens instantly.

Quick start
terminal 
npm install dpop-auth
server.ts 
import express from 'express';
import { dpopAuth, createDPoPAuth } from 'dpop-auth';

const app = express();
app.use(express.json());

const auth = createDPoPAuth(SECRET_KEY, {
  algorithm: 'ES256',
  expiresIn: 300, // 5 minutes
  enableFingerprinting: true,
});

// protect your API routes
app.use('/api/protected', dpopAuth({
  secret: SECRET_KEY,
  enableFingerprinting: true,
}));

// protected endpoint
app.get('/api/protected/data', (req, res) => {
  res.json({
    message: 'Protected from scraping and token theft!',
    user: req.token.sub,
    device: req.thumbprint,
  });
});

app.listen(3000);
